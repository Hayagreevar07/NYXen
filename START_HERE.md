
## 🔧 Technology Choices Made

### Frontend: Why React + Vite?
- **React:** Industry standard, component-based, huge ecosystem
- **Vite:** Lightning-fast dev server, modern bundler
- **TypeScript:** Type safety, better DX, fewer bugs
- **Tailwind:** Utility-first, responsive, cybersecurity theme ready

### Backend: Why Express + Node.js?
- **Node.js:** JavaScript ecosystem, async-friendly
- **Express:** Minimal, flexible, middleware-based
- **TypeScript:** Consistency with frontend, type safety
- **MongoDB:** Document model suits flexible threat data

### Why Gemini API?
- Advanced reasoning about threats
- Explainable decisions
- Recommendation generation
- Behavioral analysis
- Real-time processing

### Why Elastic?
- Real-time event indexing
- Powerful search capabilities
- Anomaly detection
- Correlation analysis
- Dashboard visualization

## 🚢 Deployment Paths

### Path 1: Google Cloud Run (Recommended for Hackathon)
```bash
# Backend to Cloud Run
gcloud run deploy nyxen-backend \
  --source . \
  --platform managed

# Frontend to Firebase Hosting
firebase deploy --only hosting
```

**Time:** 30 minutes
**Cost:** Free tier available
**Scalability:** Automatic

### Path 2: Docker Compose (Local Production Testing)
```bash
docker-compose up -d
# Everything running on localhost
```

**Time:** 5 minutes
**Cost:** Free (local only)
**Good For:** Development, testing, demos

### Path 3: Kubernetes (Enterprise Scale)
```bash
kubectl apply -f deployment.yaml
kubectl apply -f service.yaml
```

**Time:** 20 minutes
**Cost:** Your cloud provider
**Scalability:** Unlimited

## 💡 Pro Tips

### Development
- Use `npm run dev` for hot reloading
- Check browser console for frontend errors
- Check terminal for backend errors
- Use TypeScript strict mode for safety

### Deployment
- Start with Docker Compose locally
- Then deploy backend to Cloud Run
- Then deploy frontend to Firebase
- Monitor logs and health checks

### Customization
- Components are in `frontend/src/components/`
- Pages are in `frontend/src/pages/`
- API routes are in `backend/src/routes/`
- Models are in `backend/src/models/`

### Security
- Change JWT_SECRET before production
- Use environment variables for secrets
- Enable HTTPS in production
- Rotate API keys regularly
